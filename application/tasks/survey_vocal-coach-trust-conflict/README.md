# AI 练声教练：信任、冲突与专业控制专项测试

这是一个独立的 200 Persona 情境问卷，只测试诊断信任和冲突处理，不重复测
一般产品需求、价格或隐私。核心问题是：展示原始证据、校准置信度、主动承认
不确定、允许用户反对，以及教师审阅/覆盖后，用户会不会真的继续采用。

## 200 人默认分层

| 分层 | Persona 代理维度 | 数量 |
| --- | --- | ---: |
| 小白 | `ind_music=None` | 50 |
| 普通爱好者/自学者 | `ind_music=Some exposure` | 50 |
| 有经验的学生/表演者/从业者 | `ind_music=Experienced` | 50 |
| 资深表演者/教师/专业决策者 | `ind_music=Veteran` | 50 |
| **合计** |  | **200** |

采用 `sampleSizePerValueGroup: 50`，确保四层各 50，而不是从混合池中抽 200。

## 设计结构

问卷共 19 题，包含五组具体 A/B 控制情境：

1. 只有分数 vs 原始证据片段、解释和个案置信度；
2. 低置信仍下结论 vs 主动承认无法确定并重录/转人工；
3. 用户反对无入口 vs 标记争议、反馈、重测并保留历史；
4. AI 与老师冲突时 AI 最终裁决 vs 教师审阅、注释/覆盖及双版本留痕；
5. 错误后静默改报告 vs 主动通知、解释、停止错误计划、重测和人工审阅；
6. “永远正确”宣传 vs 高总体准确但不绝对、显示个案置信度和适用边界。

每个核心情境后都有下一步行为选择，例如立即执行、先听证据、重录、转老师、
仅限低风险使用、暂停或放弃。这样可把“觉得 B 更好”与“真的愿意采用”分开。

## 建议分析指标

- **证据采用率**：`q3` 选择 `use_b` 或 `inspect_b_then_decide`，并结合 `q4`
  的实际下一步；
- **校准信任**：`q5` 对 B 的选择与 `q6` 的重录/人工审阅行为；
- **用户反对后的留存**：`q7` 与 `q8` 中继续但验证、收集证据或转人工的比例；
- **教师冲突可恢复性**：`q9` 使用 B 的比例，以及 `q10` 中专业采用边界；
- **错误后的信任修复**：`q12` 的修复判断与 `q13` 的真实留存行为交叉；
- **采用边界**：`q15` 可自主影响的最高决策级别；
- **专业接受度**：`q16`，重点比较 `Experienced`、`Veteran` 和
  `teacher_coach` / `institution_buyer`；
- **净信任变化**：按 Persona 比较 `q17 - q2`，同时报告下降者比例，不能只报均值。

必须分层报告四组结果。A/B 是同一受访者内的情境对比，不是随机独立样本实验，
因此可以用于识别方向和边界，不能当作真实产品转化提升或模型准确率证据。
